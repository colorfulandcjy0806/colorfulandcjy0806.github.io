# Chen Junyang — Academic Homepage

[English](README.md) · [中文说明](README.zh-CN.md) · [Live site](https://colorfulandcjy0806.github.io/)

Personal academic homepage based on the MIT-licensed [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) design and the bilingual/color-theme adaptation by [LinB203](https://github.com/LinB203/LinB203.github.io).

## Updating content

- Add or edit papers in `_data/publications.yml`. Each entry contains its venue, authors, image, bilingual description, and paper link.
- Update biography, news, projects, journey, and awards in `_pages/about.md`.
- Update global profile information in `_config.yml`.
- Citation data is refreshed daily by `.github/workflows/google_scholar_crawler.yaml` and matched to papers by title.

The website supports English/Chinese switching and six persistent accent themes.
