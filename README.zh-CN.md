# 陈骏扬 — 学术主页

[English](README.md) · [在线主页](https://colorfulandcjy0806.github.io/)

主页基于 MIT 许可的 [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io)，并沿用 [LinB203](https://github.com/LinB203/LinB203.github.io) 的双语与多配色设计。

## 如何更新

- 新增论文：编辑 `_data/publications.yml`，复制一条记录后替换会议、作者、主图、双语简介和论文链接。
- 更新个人简介、动态、开源项目、经历与荣誉：编辑 `_pages/about.md`。
- 更新姓名、邮箱和 Scholar 地址：编辑 `_config.yml`。
- 引用量由 GitHub Action 每天抓取，并按论文标题自动匹配。

网站支持中英文切换与六种主题色，访客选择会自动保存。
